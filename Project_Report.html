Complete Project Report

1. Introduction

1.1 Project Overview

CineMatch is a data science project that builds a genre-based movie recommendation system using the IMDb Top 1000 Movies Dataset sourced from Kaggle. The system allows a user to select a movie genre (e.g., "Action", "Sci-Fi", "Drama") and instantly receive a ranked list of the highest-quality movies in that genre.

The project follows a structured data science pipeline — from raw data ingestion, through cleaning and exploratory analysis, to a fully functional recommendation engine served via a Flask web application.

1.2 Problem Statement

Users often struggle to find high-quality movies within a specific genre. Simple sorting by rating can be misleading, as niche films with very few votes may appear alongside universally acclaimed blockbusters. This project solves that problem by implementing IMDB's Weighted Rating formula, which balances a movie's average rating against the volume of votes it has received, ensuring that only truly popular and highly-rated films are recommended.

3. Recommendation Algorithm (Core Logic)

[!IMPORTANT]
This section explains the crucial part — how CineMatch decides which movies to suggest and in what order.

3.1 The Problem with Simple Sorting

A naive approach would sort movies by IMDB_Rating descending. However, this has a critical flaw:

  • A movie with a 9.0 rating from 25,000 votes would rank higher than a movie with an 8.9 rating from 2,343,110 votes.
  • The first movie's rating is based on a small audience and may not be representative. The second movie has been validated by over 2 million people.

3.2 IMDB's Weighted Rating Formula

To solve this, the system uses IMDB's own Weighted Rating (WR) formula, which is a form of Bayesian averaging:

WR = (v / (v + m)) × R + (m / (v + m)) × C

Where:

Symbol Meaning Value in Our Dataset
v Number of votes for the movie (No_of_Votes) Varies per movie
m Minimum votes required to be considered 374,161 (75th percentile)
R The movie's own average rating (IMDB_Rating) Varies per movie
C The mean rating across ALL movies in the dataset 7.95

3.3 How the Formula Works

The formula is essentially a confidence-weighted blend between a movie's individual rating and the global average:

  • When v is very large (millions of votes): The term v / (v + m) approaches 1, so WR ≈ R. The movie's own rating dominates. The system trusts its rating because many people voted.
  • When v is very small (close to the minimum): The term m / (v + m) is large, so WR is pulled toward C (the global mean of 7.95). The system doesn't fully trust this rating because few people voted, so it regresses toward the average.

Example Calculation:

Movie Rating (R) Votes (v) WR Calculation Final WR
The Dark Knight 9.0 2,303,232 (2303232/2677393)×9.0 + (374161/2677393)×7.95 8.85
12 Angry Men 9.0 689,845 (689845/1064006)×9.0 + (374161/1064006)×7.95 8.63
A niche film 9.0 30,000 (30000/404161)×9.0 + (374161/404161)×7.95 8.03

All three films have the same raw IMDB Rating of 9.0, but the Weighted Rating correctly ranks The Dark Knight (2.3M votes) higher than 12 Angry Men (690K votes), and much higher than a niche film with only 30K votes.

3.4 Implementation

# Step 1: Calculate global constants
C = df['IMDB_Rating'].mean()           # C = 7.95
m = df['No_of_Votes'].quantile(0.75)   # m = 374,161

# Step 2: Apply the WR formula to every movie
def weighted_rating(row):
    v = row['No_of_Votes']
    R = row['IMDB_Rating']
    return (v / (v + m)) * R + (m / (v + m)) * C

df['Weighted_Rating'] = df.apply(weighted_rating, axis=1)

3.5 Genre Filtering

Once every movie has a Weighted Rating, the recommendation process is straightforward:

              │

│  (descending)               │

              │
              ▼
┌─────────────────────────────┐
│  Return top 10 results      │
│  with metadata               │
└─────────────────────────────┘

Implementation:

def recommend_movies(genre, top_n=10):
    # Case-insensitive genre matching
    matched = [g for g in GENRES if g.lower() == genre.lower()]
    if not matched:
        return None

    genre_col = matched[0]
    # Filter using one-hot encoded column
    filtered = df[df[genre_col] == 1].copy()

    # Sort by Weighted Rating and return top N
    filtered = filtered.sort_values('Weighted_Rating', ascending=False).head(top_n)
    return filtered

6. Conclusion

This project demonstrates a complete, end-to-end data science workflow:

  1. Problem Definition — Identified the need for a genre-based recommendation system that handles the Cold Start problem.
  2. Data Understanding — Inspected 1,000 movies across 16 features, identifying 3 columns with significant missing data.
  3. Data Cleaning — Imputed missing values with domain-appropriate strategies, converted string columns to numeric types, and one-hot encoded 21 genres.
  4. Exploratory Analysis — Generated 6 visualizations revealing that Drama dominates the dataset, vote count correlates with revenue, and ratings cluster tightly between 7.6–8.3.
  5. Recommendation Engine — Implemented IMDB's Bayesian-averaged Weighted Rating formula, which prevents low-vote movies from unfairly outranking universally acclaimed films.
  6. Web Interface — Deployed the engine as a responsive Flask web app with a premium dark-mode UI, AJAX-powered genre filtering, and animated movie cards.

The Weighted Rating formula is the intellectual core of the system. By blending a movie's individual rating with the global average — weighted by how many people voted — it produces rankings that reflect both quality and consensus. This is the same principle used by IMDB's own Top 250 list.
